# Troubleshooting by what you see

**Choose an ending/title.** The wizard does not silently choose a proposed namespace. Select an ending and enter a title, then continue. Use ASCII letters/numbers/interior hyphens for the site label. Public DNS registration is not being performed.

**Name already used on this PC.** Check My local website or the local results. Use another label if this is a new preview. Do not delete guarded ownership records to force reuse. Local conflict checking says nothing about global/exclusive namespace availability.

**Folder needs index.html.** Select the directory containing that exact file, or choose the starter. A source repository requiring npm/build output is not automatically built. Ask your developer/AI to create static output in a separate authorized folder, then select that folder.

**Unsupported path/type, symlink, too many files or content size limit.** Use the documented static formats, safe relative names and bounded output. Remove source-control directories, dependencies and unrelated files from the selected publish folder. Do not disable the checks or select an entire home directory.

**Signing unavailable after restart.** Expected: the temporary owner key was not saved. Open the existing verified preview to view it. Lasting ownership/signing and recovery require a future explicitly approved identity flow. Do not invent credentials, claim a new key is the same owner, or automatically overwrite the old name.

**Preview stopped.** Choose Start / open preview. Source and snapshots are retained. This is local protocol state, not a public web-server or router setting. If no snapshot exists, use Create your website first.

**Local trust needs recovery.** Back up the affected profile without sharing it. Use Advanced creator tools > Recover local trust only if you understand the prompt. Older profiles without a guard can be explicitly adopted as a local baseline; this does not authenticate history. Conflicting guard/pin files require a matching known trusted backup. Do not delete or lower floors to make the message disappear.

**I see my page but another device cannot.** Correct for this build. Local-only preview has no public network transport/registry. A ZIP of the app does not automatically distribute your site or identity. Public reachability, sharing and persistent ownership are separate design/approval steps.

**Normal browsers cannot find my Woo name.** Woo-specific resolution does not add a DNS root. HTTPS alias mode points to an existing public website; local native mode uses a verified custom origin only inside Woo.

**Search has no Woo match.** The local metadata index only knows registered/published records on this PC. Add a helpful title/description/aliases, or explicitly choose public web search for ordinary internet information. A remote resolution endpoint is not a remote index. Do not claim Bing/Google knows private Woo sites.

**Public search/page fails.** Check the explicit address/provider and network. Sites may show consent/challenges or unsupported behavior because popups/downloads/permissions are restricted. No certificate/security-warning bypass is provided. Try another provider only with the user's choice, not by silently retransmitting queries.

**Old icon still appears on a pinned shortcut.** The new executable and window use the supplied W icon, but a shortcut pointing at an old Desktop build still opens that old build, and OS icon caching can lag. Verify the path/version first. Do not change system security settings or delete arbitrary caches. This build does not replace existing shortcuts automatically.

**Docs save fails because the file exists.** Choose a new filename. The app avoids silently overwriting an existing export. Docs copying deliberately replaces clipboard text only when clicked; it never reads or includes profile secrets.

**AI wants a token, public storage, DNS or a lasting key.** Stop and clarify what outcome requires it. Those are not prerequisites for the local starter. Prepare a specific storage/recovery/security plan and obtain the human's explicit approval before provisioning anything.
