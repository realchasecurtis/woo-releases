# Selected-file import hardening — 0.5.1

The experimental panel now reads selected files asynchronously, in bounded 64 KiB chunks, with a 1,500,000-byte cap and five-second deadline. Only one file operation may be outstanding per app. Windows network/UNC/device paths, reserved device names, alternate data streams and ambiguous components reject before I/O. Nonregular files and symbolic links reject after lstat; the opened descriptor is checked again. Paths still come only from the trusted native picker.

Disable, close and app exit abort pending imports. Epoch and abort checks after every asynchronous boundary prevent late bytes from entering a newly enabled session. Repeated clicks cannot create parallel reads/dialogs. Pending disk operations do not synchronously block the browser main thread.

Limits: Node cannot forcibly cancel every in-flight OS filesystem operation. Deadline/cancellation returns promptly and discards results, but an unresponsive OS request keeps the single slot occupied until it settles; then its descriptor is closed in finally. Further imports report that the previous operation is still finishing. The deadline includes completion/close. This intentionally avoids unbounded abandoned work; it is not a promise to interrupt a stuck kernel or forcibly detach a device. Local drive paths may still traverse mount/junction targets; the asynchronous deadline/slot bounds apply. No system mount/security settings are changed.

Six new controlled tests cover normal read/close, oversized/nonregular/device/network rejection, growth after stat, timeout with late completion and retained single slot, cancellation and epoch invalidation. Packaged IPC checks include normal import and a controlled slow read cancelled by disabling. No actual slow network device, named pipe or user file is opened by these tests. Historical denied test classes remain excluded. No origin, permission, signature or claims boundary was relaxed.

Homepage cleanup: scope dropdown/label, provider paragraph and WOO INDEX heading are removed from the homepage. Shortcut tiles remain. Bottom labels are Create Your Woosite and Help & AI Documentation. Settings buttons use Title Case; scope/provider controls and privacy explanation remain there. Homepage submission uses the saved scope (public web/Google by default), not a removed dropdown. Native Woo search remains selectable in Settings. No claim/permission policy changed.
