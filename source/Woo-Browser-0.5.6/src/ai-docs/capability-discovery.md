# Capability discovery v1

Browser0.5.6 source candidate. Read capabilities-json through the existing trusted Help/AI documentation path, or require sdk/discovery.cjs from local trusted code. The experimental panel's existing status includes the same descriptor. No new IPC action, listener, renderer bridge or operation dispatcher exists. Untrusted pages retain no discovery/host privileges.

src/capability-descriptor.cjs is authoritative; productVersion comes from package.json. tools/generate-capabilities.cjs produces the packaged JSON and synchronizes documentation manifest version. Run it before tools/build-docs.ps1. Tests compare generator/runtime/package documentation. Read responses include explicit application/json or text/markdown MIME and remain capped at128KiB; combined clipboard docs remain capped at512KiB.

Stable IDs describe implementations, not endpoints granting authority. requiredScopes are prerequisites/informational labels; they are NOT grant tokens or a new authorization system. disabled-by-default describes the shipped default, not the current experimental enabled state (status.enabled remains authoritative). Synthetic fixture inspection never reads a real page. No live projects adapter: foundation.selectProject persists user selection and is deliberately not called. Domain claims remain closed.

Schema resource capability-schema defines descriptor and empty discovery-request objects, rejecting unknown fields. Fixed discovery/document resource validation errors: schema_error,unknown_resource,limit_exceeded. Existing adapter execution errors are unchanged and not represented as a new unified runtime protocol. Descriptor errorCodes apply only to this discovery/docs boundary. No user IDs, profiles, paths, current tabs, imported records, credentials or grant state are included. Local SDK code is trusted code, not a secure sandbox.

10 focused tests passed: five discovery/parity/resource tests and five existing experimental lifecycle/import tests. Tests use ephemeral synthetic identities only. Schema checks are focused assertions, not a full JSON Schema engine; no dependency added. No GUI test, real machine-agent integration, public networking or deployment performed. No OS/ACL changes required or made. Independent review must verify truthful classifications and existing boundary preservation before any browser build/publication.
