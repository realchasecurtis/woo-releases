This is a clean source snapshot, not private development history or a new settings patch. The existing Windows 0.5.3 binary is unchanged. Builds are unsigned and experimental, not approved for production. Domain creation remains closed; the native network is not globally live. No automatic updater is provided. Mac and iPhone downloads are unavailable.

Build tools and runtimes must be obtained separately as described in the source README. An independent clean rebuild has not been established. Existing project and third-party license terms apply; no new license is asserted by this publication.
